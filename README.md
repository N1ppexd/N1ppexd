## Featured game development project

### Nuclear Winter — [NuclearWinterCode](https://github.com/N1ppexd/NuclearWinterCode)

In 2023, I spent four weeks at Pelifarmi developing a nuclear winter game. I built systems for procedural terrain generation, camera and player movement, random events and dice rolls, and fog of war. The repository highlights the code I created for the project; the game's asset-store content isn't included.
